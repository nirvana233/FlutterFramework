# 图片引用检查工具

## 功能说明

这个Python脚本可以帮助你检查项目中的图片文件是否在`lib`目录的Dart代码中被引用。如果图片未被引用，脚本会输出该图片的路径。

## 使用方法

### 基本用法

```bash
# 检查单个图片文件
python check_unused_images.py -i /path/to/image.png

# 检查整个目录下的所有图片
python check_unused_images.py -i /path/to/images/

# 显示详细检查过程
python check_unused_images.py -i /path/to/images/ -v
```

### 参数说明

- `-i, --image`: **(必需)** 要检查的图片文件或目录路径
- `-l, --lib`: **(可选)** lib目录路径，默认使用项目的lib目录
- `-v, --verbose`: **(可选)** 显示详细的检查过程

### 使用示例

#### 1. 检查assets/images目录下的所有图片

```bash
cd <项目根目录>/tools/tools
python check_unused_images.py -i ../../assets/images/
```

#### 2. 检查特定图片文件

```bash
python check_unused_images.py -i ../../assets/images/new/common_search.png
```

#### 3. 显示详细检查过程

```bash
python check_unused_images.py -i ../../assets/images/ -v
```

#### 4. 指定自定义lib目录

```bash
python check_unused_images.py -i ../../assets/images/ -l /custom/path/to/lib
```

## 支持的图片格式

- PNG (.png)
- JPEG (.jpg, .jpeg)
- GIF (.gif)
- WebP (.webp)
- SVG (.svg)
- BMP (.bmp)

## 工作原理

1. 扫描指定路径下的所有图片文件
2. 在项目的`lib`目录中递归搜索所有`.dart`文件
3. 检查每个图片的文件名是否在Dart代码中出现
4. 输出未被引用的图片路径

## 注意事项

- 脚本通过文件名进行匹配，确保图片文件名在代码中是唯一的
- 如果图片通过变量拼接等方式引用，可能无法被检测到
- 建议定期运行此脚本来清理未使用的图片资源

## 常见问题

**Q: 为什么有些图片明明在用，却被标记为未引用？**

A: 可能是因为图片路径是通过字符串拼接或变量动态生成的。脚本只能检测到直接写在代码中的文件名。

**Q: 可以检查多个目录吗？**

A: 目前一次只能检查一个目录，但你可以多次运行脚本来检查不同的目录。

**Q: 删除未引用的图片安全吗？**

A: 建议先手动确认这些图片确实未被使用，特别是检查是否有动态引用的情况。
